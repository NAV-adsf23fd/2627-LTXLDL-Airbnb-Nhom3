# Nhóm 3 - Lập trình xử lý dữ liệu - Paris

Python version

```
3.12.14
```

Chạy pipeline với lần chạy đã lưu gần nhất, nếu không có sẽ tự động thoát
```
python run_pipeline.py
```

Lưu flags cho lần chạy này
```
--save-flags
```


Chạy với config

```
-c, --config
```

Bỏ qua bước tải dữ liệu

```
-d, --skip-download
```

Bỏ qua bước chạy LLM

```
-l, --skip-llm
```

In log chi tiết
```
-v, --verbose
```

Bỏ qua bước lọc mẫu 
```
-f, --skip-filter
```
